Where backend meets operations

The short version — what I actually spend my days doing.

I build Java / Spring Boot backends for platforms that can't afford to be flaky — insurance underwriting at PwC, and the SBI Card origination journey at TCS. Along the way I picked up the habit of also owning what happens after the code is written: the CI/CD pipeline, the Azure VM it lands on, and the dashboards that tell me if it's actually healthy.

That's turned into a genuine second skill set — Jenkins and GitHub Actions pipelines, Docker images, Nginx + Supervisor process management, and an observability stack (OpenTelemetry, Jaeger, OpenObserve) I use to catch problems before users do. I also ship a fair amount of Angular frontend when a feature needs a UI and no one else is free.

Recent focus: microservices patterns — service discovery, API gateways, event-driven flows with Kafka — and building that same rigor into my own side projects, not just work ones.
